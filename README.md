# Newton Divided Difference Interpolation

A small web app that computes and displays the **Newton divided difference interpolation polynomial** for a set of points. Built with React, TypeScript, and Vite.

**Live:** [https://davoskanyan.github.io/divided-difference/](https://davoskanyan.github.io/divided-difference/)

## Features

- Enter and edit (x, y) data points
- View the divided difference table
- See the interpolating polynomial in expanded form with fraction coefficients
- Rendered math via MathJax

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
